# Replication-McAlexander-et-al_2024
Repository for the 2nd Reproduction Games Münster 2026, replicating "They're Still There, He's All gone: American Fatalities in Foreign Wars and Right-Wing Radicalization at Home" by Richard J. McAlexander, Michael A. Rubin & Rob Williams, APSR (2024), 118, 3, pp 1577-1583. The replication includes four robustness tests.
Our R code is available in the accompanying quarto file (.qmd), which should be run on the same level as the reproduction scripts by the authors. The original paper and the author's replication package is available at https://doi.org/10.1017/S0003055423000904.
